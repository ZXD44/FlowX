# 📖 คู่มือการติดตั้งและการใช้งาน (Getting Started Guide)

ยินดีต้อนรับสู่คู่มือการตั้งค่าและใช้งาน **FlowX** ฉบับเข้าใจง่ายสำหรับผู้ใช้งานทั่วไป

---

## 📱 1. สิ่งที่ต้องเตรียมก่อนเริ่มใช้งาน

1. สมาร์ตโฟนหรือแท็บเล็ตระบบ Android เวอร์ชั่น 8.0 ขึ้นไป
2. ติดตั้งไฟล์ APK ของตัวแอปพลิเคชันเวอร์ชันล่าสุด
3. เกม GTA ที่ต้องการใช้งาน

---

## 🔑 2. การตั้งค่าสิทธิ์ที่จำเป็น (Permissions Setup)

เมื่อเปิดแอปพลิเคชันขึ้นมาเป็นครั้งแรก ระบบจะแจ้งเตือนให้เปิดสิทธิ์ 3 รายการ ซึ่งจำเป็นต่อการทำงาน:

### 1) การอนุญาตให้แสดงทับแอปอื่น (Display Over Other Apps)
- **ทำไมต้องเปิด:** เพื่อให้แอปสามารถแสดงปุ่มเมนูลอยตัว (HUD Overlay) เหนือหน้าจอเกมได้ตลอดเวลา โดยที่คุณไม่ต้องสลับแอปไปมา
- **วิธีเปิด:** กดที่ปุ่มในแอป แล้วเลื่อนเปิดสวิตช์อนุญาตสำหรับ "FlowX"

### 2) บริการการเข้าถึง (Accessibility Service)
- **ทำไมต้องเปิด:** เพื่อให้ระบบสามารถส่งคำสั่งแตะหน้าจอแทนคุณได้อย่างแม่นยำ
- **วิธีเปิด:** ไปที่ การตั้งค่าของเครื่อง > การช่วยเหลือพิเศษ (Accessibility) > แอปที่ดาวน์โหลดไว้ > เลือก **FlowX Gesture Service** > เปิดใช้งาน

### 3) การบันทึกหน้าจอ (Screen Capture Permission)
- **ทำไมต้องเปิด:** ใช้สำหรับแคปเจอร์ภาพหน้าจอเกมแบบเรียลไทม์เพื่อส่งให้ระบบ Vision วิเคราะห์ตัวเลขมินิเกม
- **วิธีเปิด:** เมื่อกดปุ่มเริ่มทำงานในแอป จะมีหน้าต่างขึ้นถามว่า "เริ่มบันทึกหน้าจอหรือไม่" ให้กดยืนยัน

---

## 🎮 3. ขั้นตอนการใช้งานจริงในเกม

```
[เปิดแอป FlowX] ➔ [เปิดสิทธิ์ครบ 3 อย่าง] ➔ [กดเริ่มบริการลอยตัว]
                             │
                             ▼
     [เข้าเกม GTA ไปยังจุดทำกิจกรรม (เหมือง หรือ จุดตกปลา)]
                             │
                             ▼
             [กดปุ่ม Start บนเมนูลอยตัว เพื่อเริ่มบอท]
```

### การใช้งานโหมดขุดแร่ (Mining Mode)
1. เดินตัวละครไปยังจุดขุดแร่ในเกม
2. กดปุ่มไอคอนเริ่มบนเมนูลอยตัว
3. บอทจะเริ่มมองหาสัญลักษณ์การขุด หรือเมื่อมินิเกมตัวเลขเด้งขึ้นมา บอทจะทำการอ่านตัวเลขโจทย์และกดปุ่มที่ถูกต้องให้เองโดยอัตโนมัติ

### การใช้งานโหมดตกปลา (Fishing Mode)
1. เดินตัวละครไปยังริมน้ำและเตรียมคันเบ็ดให้พร้อม
2. สลับโหมดบนเมนูเป็น Fishing Mode
3. กดปุ่มเริ่มทำงาน บอทจะจับจังหวะทุ่นและดึงเบ็ดให้ทันที

## 💡 4. คำแนะนำเพื่อความปลอดภัยในการเล่น (Best Practices)

- **อย่าเปิดบอททิ้งไว้ยาวนานจนผิดธรรมชาติ:** ควรหยุดพักเป็นช่วงๆ เพื่อลดความเสี่ยงจากการถูกตรวจสอบ
- **ตั้งค่าความเร็วให้เหมาะสม:** โหมด Safe หรือความเร็วระดับปกติจะมีการสุ่มความหน่วงที่เป็นธรรมชาติที่สุด
- **ปรับความสว่างหน้าจอให้อยู่ในระดับพอเหมาะ:** ระบบอ่านภาพทำงานได้ดีที่สุดเมื่อภาพมีความคมชัดและไม่มีฟิลเตอร์ตัดแสงสีฟ้าที่จัดเกินไป
