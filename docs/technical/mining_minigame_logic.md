# ⛏️ Mining Minigame Logic Documentation (V12)
ระบบตรวจจับและแก้ปริศนาตัวเลขขุดเหมือง - โปรเจกต์ MCF-ZXD44

เอกสารฉบับนี้อธิบายถึงปัญหาที่พบในเวอร์ชันก่อนหน้า (V11) และรายละเอียดการทำงานของระบบปัจจุบัน (V12) ที่ถูกปรับจูนเพื่อความแม่นยำ 100%

---

## 🛑 ปัญหาที่พบในเวอร์ชันก่อนหน้า (Root Causes)

จากการวิเคราะห์ภาพหน้าจอจริง (Screen Capture Analysis) พบปัญหาหลัก 3 ประการ:

1. **ROI (Region of Interest) ผิดตำแหน่ง**: 
   - กรอบการสแกนเดิมเริ่มต้นที่ตำแหน่งต่ำเกินไป ทำให้ตัวเลขโจทย์สีเหลืองที่อยู่ด้านบนสุดของแผงมินิเกม "หลุดขอบ" บอทจึงมองไม่เห็นโจทย์
2. **การกวนกันของสีน้ำตาล (Color Noise)**:
   - พื้นดินและหินในเหมืองมีสีน้ำตาลทอง ซึ่งมีค่าสีใกล้เคียงกับตัวเลขโจทย์ ทำให้บอทสับสนและไปพยายามอ่านตัวเลขจาก "ก้อนหิน" แทนที่จะเป็นแผงมินิเกม
3. **การประมวลผลภาพที่รุนแรงเกินไป (Over-processing)**:
   - การทำ Binarization (แปลงเป็นขาว-ดำ) แบบฟิกซ์ค่าเดิม ทำให้ตัวเลขสีทองบางส่วนหายไปหรือกลืนไปกับพื้นหลังเมื่อสภาพแสงเปลี่ยนไป

## 🛠️ Logic Workflow (V12 "Raw Vision")

ระบบ V12 ใช้กลยุทธ์ **"เน้นภาพดิบ แต่แม่นยำที่พิกัด"** โดยมีขั้นตอนดังนี้:

### 1. Dynamic ROI Alignment
- ขยายกรอบสแกนเป็น **60% (กว้าง) x 75% (สูง)** ของหน้าจอ
- ปรับค่า `ROI_Y_BIAS` เป็น **0.40** เพื่อดันกรอบสแกนขึ้นไปด้านบน ครอบคลุมตั้งแต่ตัวเลขโจทย์สีเหลืองไปจนถึงปุ่มกดด้านล่าง

### 2. Minigame Container Validation
- ตรวจสอบว่ามี "แผงสีมืด" (Dark Panel) อยู่กลางหน้าจอจริงหรือไม่ โดยการเช็คพิกเซลกลางจอ 3 จุด ถ้าเป็นสีมืด (Luma < 95) จึงจะเริ่มทำงาน เพื่อป้องกันการทำงานมั่วซั่วกลางพื้นดิน

### 3. Smart Gold Target Detection (Filtered)
- สแกนหาพิกเซลสีเหลือง/ทอง (R>140, G>100, B<130)
- **เงื่อนไขพิเศษ (V12):** พิกเซลที่เจอต้องมี "เพื่อนบ้าน" รอบข้างเป็นสีมืด (Dark Neighbors) อย่างน้อย 2 ใน 4 ทิศทาง เพื่อยืนยันว่าเป็นตัวเลขที่อยู่บนแผงสีดำเท่านั้น (กรองสีหิน/พื้นดินออก 100%)
- คำนวณหาจุดศูนย์กลาง (True Center) โดยการเฉลี่ยค่าพิกัดทั้งหมดที่ผ่านการกรอง

### 4. Raw OCR Engine
- ตัดภาพตัวเลข (Crop) ด้วยขนาดที่ใหญ่ขึ้น (90x90 px)
- **Upscaling:** ขยายภาพดิบเป็น 5 เท่าของขนาดจริง (5x Scale) เพื่อให้ Google ML Kit เห็นลายเส้นที่คมชัด
- **No Binarization:** ส่งภาพสีจริงให้ AI วิเคราะห์โดยตรง (เนื่องจาก ML Kit ถูกเทรนมาให้อ่านตัวเลขสีทองบนพื้นดำได้ดีกว่าการแปลงเป็นขาวดำเอง)

### 5. Hybrid Button Matching
- ตรวจจับปุ่มวงกลมสีขาว (Blobs) ทั้งหมด 10 ปุ่ม
- ทำการ OCR ปุ่มแต่ละปุ่มทีละตัวจนกว่าจะเจอเลขที่ตรงกับโจทย์
- สั่งการคลิกเบิ้ล (Double Tap) เพื่อป้องกันอาการแลคของเซิร์ฟเวอร์

## 📊 สรุปความเปลี่ยนแปลงด้านเทคนิค

| ฟีเจอร์ | V11 (เดิม) | V12 (ปัจจุบัน) |
| :--- | :--- | :--- |
| **สัดส่วน ROI** | 55% x 55% | 60% x 75% (ครอบคลุมขึ้น) |
| **ตำแหน่งสแกน** | เน้นกลาง-ล่าง | เลื่อนขึ้นบน (Y_BIAS 0.40) |
