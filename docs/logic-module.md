# 🧠 อธิบายตรรกะและการตัดสินใจของระบบ (System Logic & Intelligence)

เอกสารนี้อธิบายถึงขั้นตอนการคิดและการประมวลผลของบอทในแต่ละโหมด เพื่อให้ผู้พัฒนาและผู้ใช้งานเข้าใจพฤติกรรมการทำงานของระบบอย่างชัดเจน

---

## ⛏️ 1. ระบบแก้ปัญหามินิเกมขุดแร่ (Mining Logic)

เมื่อมินิเกมขุดแร่แสดงขึ้นมาบนหน้าจอ ระบบจะดำเนินขั้นตอนการตัดสินใจตามลำดับดังนี้:

```text
[ตรวจจับภาพหน้าจอ]
       │
       ├─► พบปุ่มเตือนสีฟ้า (Alert/OK)? ────► แตะเพื่อเคลียร์หน้าต่างทันที
       │
       ├─► พบกล่องมินิเกมตัวเลข?
       │        ├─► ครอปพื้นที่โจทย์ตัวเลขสีเหลือง ─► แปลงภาพเป็นขาวดำ ─► OCR อ่านค่า
       │        ├─► ค้นหาปุ่มวงกลมตัวเลขตัวเลือกทั้งหมด
       │        └─► รัน OCR ขนานกันทุกปุ่ม ─► แตะปุ่มที่ค่าตรงกับโจทย์
       │
       └─► ไม่พบมินิเกม?
                └─► ตรวจหาสัญลักษณ์ไอคอนการขุด หรือกดตามพิกัดเป้าหมายเดิม
```

### การเพิ่มประสิทธิภาพด้วย Parallel OCR
เดิมการอ่านตัวเลือกแต่ละปุ่มต้องทำทีละปุ่มเรียงกัน ทำให้เสียเวลา ระบบนี้จึงถูกออกแบบให้ส่งภาพตัดย่อยของตัวเลือกทุกปุ่มเข้าสู่ Google ML Kit พร้อมๆ กัน ทำให้ได้คำตอบและแตะสั่งการได้ภายในเสี้ยววินาที

---

## 🎣 2. ระบบช่วยตกปลาอัตโนมัติ (Fishing Logic)

ระบบตกปลาใช้การผสมผสานระหว่างการตรวจจับรูปร่าง/สี (Blob Analysis) และการอ่านข้อความ (OCR):

1. **สแกนหาจุดสนใจ (Target Spotting)**: ค้นหาวัตถุวงกลมสีขาวหรือทุ่นตกปลาในพื้นที่ที่กำหนด
2. **จับจังหวะการดึงเบ็ด (Trigger Action)**: เมื่อเกิดการเปลี่ยนแปลงตำแหน่งหรือสีของวัตถุเป้าหมาย ระบบจะส่งคำสั่งแตะหน้าจอเพื่อดึงคันเบ็ด
3. **ตรวจสอบข้อความแจ้งเตือน (Game Feedback)**:
   - ตรวจจับคำว่า *"เริ่มใหม่"* หรือ *"พลาด"* เพื่อเตรียมเริ่มรอบถัดไป
   - ตรวจจับคำว่า *"กระเป๋าเต็ม"* หากพบระบบจะหยุดบอททันทีเพื่อความปลอดภัย

## 🛡️ 3. กลไกจำลองพฤติกรรมมนุษย์ (Humanization)

บอทไม่ได้แตะที่พิกัดเดิมซ้ำๆ หรือใช้จังหวะเวลาคงที่ แต่ใช้เทคนิค 3 ด้าน:

1. **Random Coordinate Offset**: สุ่มเบี่ยงเบนพิกัดแตะ ±3 ถึง ±12 พิกเซลจากจุดศูนย์กลางเสมอ
2. **Random Hold Duration**: จำลองระยะเวลานิ้วแตะค้างไว้บนหน้าจอระหว่าง 40ms ถึง 70ms ไม่ซ้ำกันในแต่ละครั้ง
3. **Adaptive Reaction Delay**: หน่วงเวลาการตอบสนองแบบสุ่มเล็กน้อย เพื่อให้ดูเหมือนปฏิกิริยาของสายตามนุษย์
